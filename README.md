## 费用模型

设软件研制与符合性总预算为 B，验证与符合性成本占比为 A，可替代工作的占比为 E，这部分工作的费用降幅为 R，新增投入为 X：

`净节省 = B × A × E × R − X`

所有金额单位均为万元。软件净降本比例的分母为 B；验证与符合性净降本比例的分母为 B × A。两个比例不能相加。

首次示例：B=1000，A=65%，E=35%，R=50%，X=60；净节省 53.75 万元，软件净降本 5.375%，验证与符合性净降本约 8.269%。

成熟示例：B=1000，A=65%，E=45%，R=60%，X=40；净节省 135.5 万元，软件净降本 13.55%。

机型、软件等级与局方选项只提供情景说明，不施加未经证实的隐含乘数。费用范围及预设均为工程预算假设，非认证项目实测统计。额外工作成本与负收益保留，不截断为零。
